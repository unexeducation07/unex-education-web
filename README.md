# UNEX Education: sitio principal

Puerta de entrada a los productos de UNEX Education y catálogo de UNEX Apps.
Hecho con Next.js (App Router) y TypeScript. Se publica en Vercel.

## Trabajar en local

```bash
npm install     # solo la primera vez
npm run dev     # abre http://localhost:3000
npm run build   # comprueba que todo compila antes de publicar
npm run lint    # revisa el código
```

Las reglas del proyecto están en `CLAUDE.md` y la identidad visual en `docs/marca/`.
